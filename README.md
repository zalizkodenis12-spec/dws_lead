> **DenisWeb Studio** · Клон Faro Lead для ринку України · Фірмовий дизайн & Економний AI

---

## 🎯 Про проєкт

**DWS Lead** — це автоматизований Telegram Mini App сервіс для агентства **DenisWeb Studio**, створений за концепцією Faro Lead, але повністю оптимізований під український ринок та фірмовий стиль студії:
- **0-Cost Smart-фільтр:** моніторинг ~200 чатів та ~200 каналів без витрати AI-токенів на спам чи резюме шукачів.
- **On-Demand AI:** виклик AI-рейтингу (0–100), стислого опису та генерації відгуку тільки тоді, коли ви натискаєте на картку (зі стильними сірими **Skeleton Loaders** анімаціями).
- **Підтримка Google Gemini / Google AI Plus:** безкоштовний офіційний ключ з [Google AI Studio](https://aistudio.google.com/app/apikey).
- **Повна CRM-система:** 10 статусів воронки (*Follow-up, В процесі, Працюєм, Оффер, Закритий, Відмова тощо*), швидка кнопка прямого переходу в діалог із замовником у Telegram, облік вартості робіт та дедлайнів.
- **Аналітика доходу:** інтерактивний графік по місяцях, загальний заробіток, очікувані надходження, акордеон оплат за тижнями та днями.
- **Фірмовий дизайн DenisWeb Studio:** кольори `#0066FF`, `#0F0F0F`, `#FFFFFF`, шрифти Outfit + Inter, плавний перемикач **Світла / Темна теми** та 4% шум.

## 🚀 Швидкий запуск

### 1. Встановлення залежностей
```bash
cd dws-lead
npm install
```

### 2. Налаштування `.env`
Відкрийте файл `dws-lead/.env` і заповніть ваші ключі:
- `TELEGRAM_BOT_TOKEN` — отримайте у [@BotFather](https://t.me/BotFather).
- `GEMINI_API_KEY` — безкоштовний ключ у [Google AI Studio](https://aistudio.google.com/app/apikey) (під вашим акаунтом з Google AI Plus).
- `TELEGRAM_CHAT_ID` — ваш особистий ID у Telegram (через [@userinfobot](https://t.me/userinfobot)).

### 3. Запуск сервера та веб-додатка
```bash
npm start
```
Додаток стане доступний за адресою: **`http://localhost:3000`**.  
Відкрийте її в браузері — ви побачите повноцінний інтерактивний інтерфейс з усіма 4 вкладками, тестовою вакансією, CRM та доходами.

### 4. Запуск Telegram Бота
```bash
npm run bot
```
Бот автоматично додасть постійну кнопку **Menu Button** (*🚀 DWS Lead*) у чаті Telegram та надсилатиме інлайн-кнопку запуску по команді `/start`.

## 📱 Розбір 4 головних вкладок

### 1. 📋 Заявки
- Стрічка замовлень у реальному часі.
- Фільтри: Ніші (*Веброзробка: Лендінги, Магазини, 3D, Каталоги; Маркетинг; Монтаж*), бюджет, досвід, сортування.
- Кнопка **«Взяти в роботу»** — миттєво клонує лід у CRM.
- Кнопка **«AI-відгук»** — показує skeleton-завантаження і генерує персоналізований оффер з пропозицією безкоштовного демо, копіюванням та прямим посиланням у діалог із клієнтом.
- Бейдж **AI 85/100** — детальний скоринг переваг і нюансів замовлення.

### 2. 📊 CRM
- Воронка з 10 статусів (*Всі, В процесі, Працюєм, Оффер, Закритий, Follow-up, Обговорити пізніше, Ігнорує, Відмова, Не співпрацюєм*).
- Картка клієнта: пряма кнопка **«НАПИСАТИ В TELEGRAM»**, контакти, послуга, бюджет, статус оплати (Не оплачено / Частково / Оплачено), дедлайн у календарі, замітки.
- Кнопка **«+ Клієнт»** для ручного додавання замовника з будь-якого джерела (*Партнери, TikTok, Холодні, Реклама*).

### 3. 💰 Дохід
- Віджети: **Зароблено** (120 500 ₴) та **Очікувано** (20 000 ₴).
- Стовпчиковий інтерактивний графік за місяцями (Чер, Лип, Сер, Вер, Жов).
- Акордеон по тижнях та днях (1–7 жовтня: 1000 ₴, 2500 ₴, 500 ₴...) за малюнком з блокнота.
- Кнопка **«+ Замовлення»** для фіксації нових оплат.

### 4. 👤 Профіль
- Текстове поле **«ПРО СЕБЕ»** (до 2000 символів) — опис досвіду, навичок та переваг студії.
- Текстове поле **«ШАБЛОН ВІДГУКУ»** (до 2000 символів) — базовий шаблон першого повідомлення.
- Перемикач **Тема**: Світла / Темна.
- Керування базою джерел: перегляд та редагування списку ~200 чатів і ~200 каналів.

## 🤖 Модуль моніторингу чатів та каналів (~200 чатів + ~200 каналів)

Файл `backend/parser/sources.json` містить базу цільових українських ресурсів:
- Ви можете додати або замінити список своїми юзернеймами прямо через вкладку **«Профіль»** -> **«Керувати списком чатів та каналів»** у додатку, або відредагувати `sources.json`.
- Всі вхідні повідомлення проходять через евристичний фільтр `backend/parser/filter.js`:
  - Миттєво відсікає спам, крипту, казино та резюме джунів.
  - Визначає клієнтський намір і витягує орієнтовний бюджет.
  - Жоден кредит AI не витрачається дарма!
